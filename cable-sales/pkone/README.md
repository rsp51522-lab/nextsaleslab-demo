# PKONE 月末実績

- [営業・メンテ月末集計](https://rsp51522-lab.github.io/nextsaleslab-demo/cable-sales/pkone/)
- [営業売上の詳細集計](https://rsp51522-lab.github.io/nextsaleslab-demo/cable-sales/)
- [営業単価マスター](https://rsp51522-lab.github.io/nextsaleslab-demo/cable-sales/price-master/)

営業実績管理表（.xls）、月次確定ファイル（.xlsx）、年間管理表（.xlsx）をブラウザ内で読み込みます。営業・メンテ・キャンセルの確定金額は月次確定ファイルを基準にし、更新した年間管理表を保存できます。

単価マスターは商品別の参考計算に使います。変更した単価は端末に保存され、JSONで書き出し・読み込みができます。確定金額を単価計算で上書きしません。
