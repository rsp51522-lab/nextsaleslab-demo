# PKONE 月末実績

GitHub Pages: https://rsp51522-lab.github.io/nextsaleslab-demo/cable-sales/pkone/

営業実績管理表（.xls）、月次確定ファイル（.xlsx）、2026年の年間管理表（.xlsx）をこの順で読み込み、対象月を選んで保存します。ファイルはブラウザ内で処理されます。

確定ファイルの「実績」シートを営業・メンテの確定売上と拠点別内訳の基準にします。営業実績管理表から担当者別の戸建真水とキャンセル真水を読み込みます。2026年ファイルでは「部署売上」の対象月の営業・メンテ内訳と件数、「営業」の担当者別獲得・キャンセルを更新し、他の月と数式を残します。Excelで開いた際に数式を再計算する設定を加えています。

サンプルの2026年9月確定ファイルは営業 2,977,100円、メンテ 1,022,400円、合計 3,999,500円です。営業実績管理表の契約日と選択月が違う場合、画面に警告します。元ファイルに既存値がある場合は対象セルを置き換える旨を表示します。
